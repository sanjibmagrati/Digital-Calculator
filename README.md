# Digital Calculator

A clean, modern web-based calculator built with pure HTML, CSS, and JavaScript. This project includes a realistic calculator interface with AC, backspace, percentage, operators, decimals, and equals functionality. The layout fully replicates a physical calculator with responsive button sizing, and clear visual hierarchy.

- AC button
